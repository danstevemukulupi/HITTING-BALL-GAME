
# 🎮 Hitting Ball Game

An interactive browser-based arcade game inspired by the classic brick-breaker genre, developed as part of the **Graphic Programming** module at **Atlantic Technological University**.

Players control a custom-designed skateboard paddle to keep a Pacman-style ball in play while breaking all the bricks to achieve victory.

---

## 📖 Overview

The Hitting Ball Game is a fun and engaging web application built using **HTML**, **CSS**, and **JavaScript**. The project demonstrates fundamental game development concepts including animation, collision detection, event-driven programming, and responsive user interaction.

This project was created to strengthen practical skills in browser-based game development using the HTML5 Canvas API.

---

## ✨ Features

* 🕹️ Interactive brick-breaker gameplay
* 🛹 Custom skateboard-inspired paddle
* 👾 Pacman-style animated ball
* 💥 Accurate collision detection
* 🧱 Brick destruction mechanics
* 📈 Real-time score tracking
* ⌨️ Keyboard controls
* 🖱️ Mouse paddle movement
* ⏯️ Game start and pause functionality
* 🔄 Automatic game reset after winning or losing
* 🎨 Colourful and responsive game interface
* ⚡ Smooth animations using `requestAnimationFrame()`

## 🚀 Getting Started

### Clone the repository

```bash
git clone https://git@github.com:danstevemukulupi/HITTING-BALL-GAME.git
```

### Navigate into the project

```bash
cd HITTING-BALL-GAME
```

### Run the project

Since this is a static web project, no installation is required.

Simply open the `index.html` file in your browser.

Alternatively, if you use **Visual Studio Code**, you can:

1. Open the project folder.
2. Install the **Live Server** extension.
3. Right-click **index.html**.
4. Select **Open with Live Server**.

The game will automatically launch in your browser.
